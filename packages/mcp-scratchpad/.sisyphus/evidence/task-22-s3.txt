2.1 create_s3_filesystem Function
---------------------------------

Signature:
    def create_s3_filesystem(bucket: str, **options: Any) -> AbstractFileSystem

Features:
    - Creates S3FileSystem wrapped with DirFileSystem
    - Bucket name can include path prefix (e.g., "mybucket/data/subdir")
    - Credential options: key, secret, token
    - Client kwargs: endpoint_url for MinIO/testing, region_name
    - Caching options: use_listings_cache, listings_expiry_time
    - Graceful handling when s3fs not installed (S3NotInstalledError)

Credential Priority (highest to lowest):
    1. Direct key/secret/token parameters
    2. client_kwargs dict
    3. Environment variables (AWS_*, Boto3 defaults)
    4. AWS credentials file
    5. IAM role (when on AWS)

2.2 Error Handling
------------------

- S3NotInstalledError: Raised when s3fs package is not installed
- ValueError: Raised when bucket name is empty
- Warning logged for unused options

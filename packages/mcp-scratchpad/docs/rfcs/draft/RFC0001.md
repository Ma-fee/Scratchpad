## 简而言之
 
> **快速概要**：使用fsspec实现面向MCP Scratchpad的多层叠加文件系统架构，支持S3/本地/内存后端，并通过`scratchpad://` URI方案实现会话范围的写时复制及MCP资源集成。
 
>
 
> **交付成果**：
 
> - 基于配置的挂载系统，具有覆盖语义
 
> - 每会话叠加视图的SessionFileSystemManager
 
> - 具有写时复制和白洞支持的叠加文件系统
 
> - 用于 `scratchpad://` URI 的 MCP 资源处理程序
 
> - 支持多模态文件（图片、PDF），并具备客户端能力检测功能
 
> - 用于提升性能的目录索引缓存
 
> - 采用TDD方法实现全面测试覆盖
 
>
 
> **预计工作量**：较大（5周，5个阶段）
 
> **并行执行**：是——每个阶段内的波浪
 
> **关键路径**：配置 → 会话管理器 → OverlayFS → 资源 → 集成

## 工作目标
 
### 核心目标
 
用支持多种后端（本地、S3、内存）的多层叠加文件系统架构替换当前的FileSystemStore，同时保持与现有MCP工具的向后兼容性，并新增对完整MCP资源的支持。 
### 具体交付成果
 
- `config/models.py`：MountConfig 和 OverlayConfig Pydantic 模型
 
- `fs/session_manager.py`：用于每个会话的 FS 管理器 SessionFileSystemManager
 
- `fs/overlay.py`：带有写时复制和白洞实现的叠加文件系统
 
- `fs/cache.py`：带TTL和事件驱动失效的目录索引缓存
 
- `resources/scratchpad_resources.py`：用于处理`scratchpad://` URI 的MCP资源处理器
 
- `security/path_validation.py`：路径遍历防护
 
- 完整测试套件：单元测试/集成测试/端到端测试/性能测试/安全测试/

### 必备（在范围之内）
 
- 具有上层（可读写）和下层（只读）的多层叠加文件系统
 
- 会话范围的文件系统隔离
 
- 写时复制（COW）语义
 
- 文件删除的白屏机制
 
- 目录索引缓存
 
- 支持本地、S3 和内存后端
 
- 带有`scratchpad://` URI方案的MCP资源
 
- 多模态文件支持（图片、PDF）
 
- 路径遍历防护
 
- 配置驱动的挂载系统
 
### 不得具备（护栏 - 范围外）
 
- **NFS/SMB 支持**：明确推迟至未来的 RFC
 
- **实时协作**：不支持实时并发编辑或WebSocket同步
 
- **内置迁移工具**：对 .metadata.json 的重大变更，仅支持手动导出
 
- **Git 集成**：版本控制仅限于乐观锁
 
- **文件级ACL**：仅支持挂载级只读/读写权限
 
- **静止数据加密**：存储层职责
 
- **分布式一致性**：单节点部署假设
 
- **跨会话资源订阅**：订阅仅限于单个会话内

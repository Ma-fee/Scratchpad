## Summary
Successfully implemented directory whiteout handling for OverlayFileSystem.

## Implementation Details

### 1. rmdir() Method (line 783-850 in overlay.py)
- Implements directory deletion with whiteout support
- For directories in upper layer: deletes directly
- For directories in lower layer only: creates `.wh.<dirname>` marker in upper layer
- Raises FileNotFoundError if directory doesn't exist
- Raises NotADirectoryError if path is a file
- Raises OSError if directory is not empty
- Idempotent: calling rmdir on already whited-out directory returns without error

### 2. isdir() Method (line 347-382 in overlay.py)
- Updated to check for directory whiteout markers
- Returns False if a whiteout marker exists for the directory path
- This ensures whited-out directories are not treated as directories

### 3. ls() Method (line 217-308 in overlay.py)
- Updated to return empty list if directory has whiteout marker
- This prevents listing contents of whited-out directories
- Documentation updated to mention directory whiteout behavior

### 4. mkdir() Method (line 994-1031 in overlay.py)
- Updated to call `_remove_whiteout()` before creating directory
- This enables "recreate after delete" scenario
- If directory was previously whited out, the whiteout is removed

### 5. makedirs() Method (line 1033-1074 in overlay.py)
- Updated to call `_remove_whiteout()` before creating directories
- Enables recreating directory trees after deletion

### 6. _remove_whiteout() Method (line 660-687 in overlay.py)
- Already existed for files
- Also works for directories (same naming convention)
- Removes whiteout marker from upper layer if it exists

## Directory Whiteout Convention
- Uses same pattern as file whiteouts: `.wh.<dirname>`
- Placed in parent directory
- Example: Deleting `/foo/bar` creates `/foo/.wh.bar`
- Hides entire directory tree from lower layers

## Behavior Verification

### Given: Lower layer has /testdir with content
```python
lower.mkdir("/testdir")
lower.write_text("/testdir/file.txt", "content")
```

### When: Delete directory via overlay
```python
overlay.rm("/testdir/file.txt")  # Delete file first
overlay.rmdir("/testdir")         # Delete directory
```

### Then:
- `overlay.exists("/testdir")` returns False
- `overlay.isdir("/testdir")` returns False  
- `upper.isfile("/.wh.testdir")` returns True (whiteout created)
- `lower.isdir("/testdir")` returns True (lower unchanged)

### When: Recreate directory
```python
overlay.mkdir("/testdir")
```

### Then:
- `overlay.exists("/testdir")` returns True
- `overlay.isdir("/testdir")` returns True
- `upper.isfile("/.wh.testdir")` returns False (whiteout removed)

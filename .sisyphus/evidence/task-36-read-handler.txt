5. API USAGE
================================================================================

Example 1: Read a text file
    >>> from mcp_scratchpad.resources import read_resource
    >>> result = read_resource("scratchpad://abc-123/workspace/file.txt")
    >>> result.success
    True
    >>> result.content.data
    'Hello, World!'
    >>> result.metadata.mime_type
    'text/plain'

Example 2: Read a binary file
    >>> result = read_resource("scratchpad://abc-123/image.png")
    >>> result.content.is_binary
    True
    >>> result.content.encoding
    'base64'
    >>> result.metadata.content_type
    'image'

Example 3: Error handling
    >>> result = read_resource("scratchpad://invalid/file.txt")
    >>> result.success
    False
    >>> result.error
    "Session not found: invalid"

Example 4: Helper functions
    >>> text = read_resource_text("scratchpad://abc-123/config.json")
    >>> bytes_data = read_resource_bytes("scratchpad://abc-123/image.png")

7. MIME TYPE DETECTION SIGNATURES
================================================================================

Content-based detection using file magic numbers:
  PNG:  b'\x89PNG\r\n\x1a\n'
  JPEG: b'\xff\xd8\xff'
  GIF:  b'GIF87a' or b'GIF89a'
  WEBP: b'RIFF....WEBP'
  PDF:  b'%PDF-'
  ZIP:  b'PK\x03\x04'
  GZIP: b'\x1f\x8b'
  TAR:  b'ustar\x00'

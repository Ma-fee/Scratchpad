Whiteout Convention
-------------------
- Marker format: .wh.<filename>
- Example: deleting /dir/file.txt creates .wh.file.txt in upper layer

New Methods in OverlayFileSystem
--------------------------------

1. _get_whiteout_path(path: str) -> str
   - Returns the whiteout marker path for a given file path
   - Example: /file.txt -> /.wh.file.txt

2. _has_whiteout(path: str) -> bool
   - Checks if a whiteout marker exists in upper layer

3. _get_whited_out_files(dir_path: str) -> set[str]
   - Returns set of filenames with whiteout markers in a directory

4. _create_whiteout(path: str) -> None
   - Creates empty whiteout marker file in upper layer
   - Creates parent directories as needed

5. _resolve_without_whiteout(path) -> tuple | None
   - Internal resolve that ignores whiteout markers
   - Used by exists() and rm() for proper layering semantics

6. rm(path: str, **kwargs) -> None
   - Removes file with whiteout support:
     * If file in upper layer: deletes it directly
     * If file in lower layer only: creates whiteout marker
     * If already whited-out: idempotent (no-op)
   - Raises FileNotFoundError if path doesn't exist
   - Raises IsADirectoryError for directories

Modified Methods
----------------

1. ls(path: str) -> list[str]
   - Now filters out:
     * .wh.* marker files (hidden from view)
     * Files that have whiteout markers (appear deleted)

2. exists(path: str) -> bool
   - Now returns False if whiteout marker exists for path
   - Whiteout markers hide files from lower layers

3. _resolve(path: str) -> tuple | None
   - Now returns None if whiteout marker exists
   - Path is considered non-existent when whited-out

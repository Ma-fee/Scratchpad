DATACLASS DEFINITIONS
---------------------

DirectoryEntry:
  - name: str - Entry name (filename or directory name)
  - type: str - Entry type ('file' or 'directory')
  - size: int - File size in bytes (0 for directories)
  - mimetype: Optional[str] - MIME type (None for directories)
  - modified_time: Optional[str] - ISO format timestamp
  - to_dict(): Convert to dictionary representation

DirectoryListingResult:
  - uri: str - Original scratchpad:// URI
  - session_id: str - Session identifier
  - path: str - Directory path within session
  - entries: list[DirectoryEntry] - List of directory entries
  - total_count: int - Total number of entries
  - has_more: bool - Whether more entries exist beyond this page
  - offset: int - Current skip count
  - limit: int - Current page size
  - success: bool - Operation success status
  - error: Optional[str] - Error message if failed
  - to_dict(): Convert to dictionary representation

FUNCTION SIGNATURE
------------------
def read_directory_resource(
    uri: str,
    session_manager: Optional[SessionFileSystemManager] = None,
    limit: int = 100,
    offset: int = 0,
) -> DirectoryListingResult

PAGINATION SUPPORT
------------------
- Default limit: 100 entries per page
- Offset-based pagination for large directories
- has_more flag indicates if more entries exist
- Parameters returned in result for client tracking

ERROR HANDLING
--------------
The function handles these error cases gracefully:
  - Invalid URI scheme
  - Empty URI
  - Missing session_id
  - Session not found
  - Resource not found (directory doesn't exist)
  - Resource is not a directory
  - Session manager not available
  - Directory listing failure (ls error)

Each error returns a DirectoryListingResult with:
  - success=False
  - Descriptive error message
  - Other fields set to default/empty values

PER ENTRY METADATA
------------------
Each directory entry includes:
  - name: Filename or directory name
  - type: 'file' or 'directory'
  - size: File size in bytes (0 for directories)
  - mimetype: Auto-detected MIME type using detect_mime_type()
  - modified_time: ISO format last modification timestamp

RESOURCE URI PATTERN
--------------------
- scratchpad://{session_id}/{file_path}
  - session_id: UUID4 session identifier
  - file_path: File path within session (supports nested paths)

INTEGRATION POINTS
------------------
- SessionFileSystemManager: Provides per-session filesystem instances
- FastMCP @mcp.resource() decorator: Registers handlers with URI template
- MemoryFileSystem: Upper layer for session writes
- Automatic MIME type detection: Returns appropriate content types

ERROR HANDLING
--------------
- SessionNotFoundError: Raised when session doesn't exist or expired
- ResourceNotFoundError: Raised when file doesn't exist
- IsADirectoryError: Raised when trying to read a directory
- FileNotFoundError: Converted for MCP protocol compatibility

4. API USAGE EXAMPLES
================================================================================

Create BinaryResource:
----------------------
from mcp_scratchpad.resources.binary_handler import BinaryResource

resource = BinaryResource(
    uri="scratchpad://abc-123/document.pdf",
    session_id="abc-123",
    path="/document.pdf",
    binary_content=base64.b64encode(pdf_bytes).decode(),
    binary_format="PDF",
    mime_type="application/pdf",
    size_bytes=len(pdf_bytes),
    pdf_metadata=PDFMetadata(page_count=42, title="Report"),
)

Process PDF file:
-----------------
from mcp_scratchpad.resources.binary_handler import process_pdf_resource

result = process_pdf_resource(
    uri="scratchpad://abc-123/doc.pdf",
    fs=filesystem,
    session_id="abc-123",
    path="/doc.pdf",
    file_size=102400,
    extract_text=True,
    max_pages=2,
)

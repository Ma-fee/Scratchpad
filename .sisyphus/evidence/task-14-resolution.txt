## Implementation Details

### `_resolve(path: str) -> tuple[AbstractFileSystem, str, int] | None`

Returns a tuple of (filesystem, relative_path, layer_index) if found:
- `layer_index = 0`: Upper layer (highest priority)
- `layer_index = 1, 2, ...`: Lower layers in priority order
- Returns `None` if file not found in any layer

### Resolution Order
1. Check upper layer first (read-write, highest priority)
2. Check lower layers in order (read-only, first in list = higher priority)
3. Return first match found

### Helper Functions Added

1. `_normalize_path(path: str) -> str`: Normalizes paths to start with '/'
2. `_exists_in_layer(fs, path) -> bool`: Checks if path exists in specific layer
3. `_get_layer_fs(layer_index: int) -> AbstractFileSystem`: Gets filesystem for layer index

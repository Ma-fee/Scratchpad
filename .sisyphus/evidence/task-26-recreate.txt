Edge Cases Verified:
--------------------

1. File exists in lower layer -> deleted (whiteout created) -> recreated in upper layer
   - Whiteout marker is properly removed
   - Recreated file is visible in ls()
   - Recreated file is accessible via exists() and isfile()
   - Can read/write to recreated file
   - Lower layer remains unchanged

2. Multiple delete-recreate cycles
   - Whiteout mechanics work correctly in each cycle
   - File state transitions properly between layers

3. Different write modes
   - "w" mode: truncates and recreates file, whiteout removed
   - "a" mode: appends to file, whiteout removed (COW + append)
   - "w+" mode: read/write mode, whiteout removed

Example Usage:
--------------

    # File exists in lower layer
    lower.write_text("/file.txt", "original")
    overlay = OverlayFileSystem(upper, [lower])
    assert overlay.exists("/file.txt") is True

    # Delete creates whiteout
    overlay.rm("/file.txt")
    assert overlay.exists("/file.txt") is False  # Hidden by whiteout
    assert upper.isfile("/.wh.file.txt") is True  # Whiteout marker exists

    # Recreate removes whiteout and creates new file
    with overlay.open("/file.txt", "w") as f:
        f.write("recreated")
    assert overlay.exists("/file.txt") is True  # Now visible
    assert upper.isfile("/.wh.file.txt") is False  # Whiteout removed
    assert upper.isfile("/file.txt") is True  # New file in upper

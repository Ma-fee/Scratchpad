## QA Scenario: Write mode triggers COW

**Steps:**
1. lower.write_text("/file.txt", "original")
2. overlay = OverlayFileSystem(upper, [lower])
3. with overlay.open("/file.txt", "w") as f:
     f.write("modified")
4. assert upper._store["/file.txt"] == b"modified"
5. assert lower._store["/file.txt"] == b"original"

**Result:** COW triggered, upper modified, lower unchanged ✓

## Supported Modes

| Mode | Description | COW Trigger | Target Layer |
|------|-------------|-------------|--------------|
| r    | Read only   | No          | Resolved     |
| rb   | Binary read | No          | Resolved     |
| w    | Write       | Yes         | Upper        |
| wb   | Binary write| Yes         | Upper        |
| a    | Append      | Yes         | Upper        |
| ab   | Binary append| Yes        | Upper        |
| r+   | Read+write  | Yes         | Upper        |
| w+   | Write+read  | Yes         | Upper        |
| a+   | Append+read | Yes         | Upper        |

## Implementation Summary

### CacheEntry Dataclass
- path: str - directory path
- entries: list[str] - list of file/directory names
- created_at: float - Unix timestamp
- ttl: int - time-to-live in seconds

### CacheConfig Dataclass
- default_ttl: int = 60 (seconds)
- max_size: int = 1000 (max entries)
- enabled: bool = True

### DirectoryIndexCache Class
- __init__(default_ttl=60, max_size=1000, config=None)
- get(path) -> list[str] | None: returns entries if not expired
- set(path, entries, ttl=None): stores with timestamp, validates TTL
- delete(path) -> bool: removes entry, returns True if existed
- clear(): removes all entries
- _is_expired(entry) -> bool: checks if TTL exceeded
- _evict_oldest(): removes oldest entry when full
- has_entry(path) -> bool: checks if entry exists (not checking expiration)
- get_stats() -> dict: returns cache statistics

## Design Decisions
- TTL validation happens at entry creation and in set()
- Expired entries are lazily deleted on access
- Entries list is copied on set() to prevent external modification
- Oldest entry evicted when max_size reached (FIFO eviction)
- Disabled cache returns None for all get() calls
- Config takes precedence over individual init parameters

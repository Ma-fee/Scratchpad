IMPLEMENTATION SUMMARY
================================================================================

Added streaming capabilities to OverlayFileSystem in:
  src/mcp_scratchpad/fs/overlay.py

New Methods Implemented:
  1. cat_file(path, start=None, end=None) -> bytes
     - Reads file contents with optional byte range support
     - Efficiently delegates to underlying filesystem
     - Supports partial reads for large files

  2. cat(paths, recursive=False, on_error='raise') -> bytes | dict
     - Batch read files from one or more paths
     - Returns bytes for single path, dict for multiple paths
     - Error handling: raise, omit, or return exceptions

  3. _cat_file_streaming(path, chunk_size=None) -> Iterator[bytes]
     - Generator-based streaming for memory-efficient reading
     - Yields chunks of configurable size (default: 64KB)
     - Does not load entire file into memory

  4. size(path) -> int | None
     - Returns file size in bytes
     - Returns None for directories or non-existent paths

  5. is_streaming_file(path, threshold=None) -> bool
     - Checks if file should be streamed (> 1MB by default)
     - Configurable threshold for streaming decisions

Constants:
  - _STREAM_THRESHOLD = 1MB (1024 * 1024 bytes)
  - _DEFAULT_CHUNK_SIZE = 64KB (64 * 1024 bytes)

================================================================================
EXAMPLE USAGE
================================================================================

# Check if file needs streaming
if overlay.is_streaming_file("/large.bin"):
    # Stream in chunks
    for chunk in overlay._cat_file_streaming("/large.bin"):
        process_chunk(chunk)
else:
    # Load entire file (small files)
    content = overlay.cat_file("/small.txt")

# Read specific byte range (efficient partial reads)
header = overlay.cat_file("/large.bin", start=0, end=1024)
footer = overlay.cat_file("/large.bin", start=-1024)

# Batch read multiple files
contents = overlay.cat(["/file1.txt", "/file2.txt", "/file3.txt"])

# Get file size
total_size = overlay.size("/large.bin")

## Implementation Summary

Implemented the following methods in `src/mcp_scratchpad/fs/overlay.py`:

### 1. `_get_all_whiteouts(dir_path: str = "/") -> list[WhiteoutEntry]`
   - Recursively scans the upper layer for whiteout markers
   - Returns a list of WhiteoutEntry objects with metadata
   - Handles nested directories correctly

### 2. `_is_stale_whiteout(path: str) -> bool`
   - Checks if a whiteout marker is stale (no longer hiding anything)
   - A whiteout is stale if:
     a. The hidden file/directory no longer exists in any lower layer
     b. OR the file was removed from lower layers by external means
   - Returns False if no whiteout marker exists at the path

### 3. `find_stale_whiteouts(dir_path: str = "/") -> list[WhiteoutEntry]`
   - Finds all stale whiteout markers in the overlay filesystem
   - Returns WhiteoutEntry objects for stale whiteouts only
   - Does NOT remove them - use cleanup_stale_whiteouts() for that

### 4. `cleanup_stale_whiteouts(dir_path: str = "/") -> list[str]`
   - Removes all stale whiteout markers from the upper layer
   - Returns list of removed whiteout marker paths
   - Preserves valid whiteouts (those still hiding files in lower layers)
   - Handles errors gracefully (skips entries that can't be removed)

### 5. `get_whiteout_stats(dir_path: str = "/") -> dict[str, Any]`
   - Returns statistics about whiteout markers
   - Includes:
     - total: Total number of whiteout markers
     - stale: Number of stale whiteouts
     - valid: Number of valid (active) whiteouts
     - by_layer: Dictionary mapping layer index to count

```python
    path: str                    # The path that is whited out

    created_at: float = field(default_factory=time.time)
    expires_at: float | None = None
    layer_index: int = 0        # The layer index of the hidden file
```

## Stale Whiteout Definition

A whiteout is "stale" when:
- The file/directory it hides no longer exists in any lower layer
- This can happen when:
  a. The whiteout was created for a file that was subsequently deleted from all lower layers
  b. The file was removed by external means (outside the overlay filesystem)
  c. Only valid whiteouts should remain after cleanup

## Example Usage

```python
from mcp_scratchpad.fs.overlay import OverlayFileSystem

# Create overlay
overlay = OverlayFileSystem(upper, [lower])

# Find stale whiteouts
stale = overlay.find_stale_whiteouts("/")
for entry in stale:
    print(f"Stale whiteout: {entry.whiteout_path} for {entry.path}")

# Cleanup stale whiteouts
removed = overlay.cleanup_stale_whiteouts("/")
print(f"Removed {len(removed)} stale whiteouts")

# Get statistics
stats = overlay.get_whiteout_stats("/")
print(f"Total: {stats['total']}, Stale: {stats['stale']}, Valid: {stats['valid']}")
```

Scenario: Local filesystem with path prefix
-------------------------------------------

Steps:
  1. Create temp directory /tmp/test/base
  2. fs = create_local_filesystem(path_prefix="/tmp/test/base")
  3. fs.write_text("/file.txt", "content")
  4. assert Path("/tmp/test/base/file.txt").exists()

Result: PASSED
Expected: File created under prefix

Notes

- DirFileSystem provides chroot-like semantics where the prefix becomes the root
- Access to paths outside the prefix is blocked by the DirFileSystem wrapper
- Options are passed through to LocalFileSystem constructor
- All operations work correctly through both direct and prefixed filesystems

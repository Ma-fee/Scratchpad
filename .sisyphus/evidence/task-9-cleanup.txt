Implementation Details:
=======================

1. Session Tracking Enhancements:
   - Added _session_metadata dict to track SessionMetadata per session
   - Added _last_accessed dict to track last access timestamps
   - Modified create_session() to accept optional metadata dict
   - Modified create_session() to initialize SessionMetadata with creation time
   - Modified create_session() to track initial last_accessed timestamp

2. Enhanced get_session_fs():
   - Updates last_accessed timestamp on each access
   - Updates SessionMetadata.last_accessed as well

3. Enhanced cleanup_session():
   - Returns True if session was found and cleaned up
   - Returns False if session already cleaned/didn't exist (idempotent)
   - Clears MemoryFileSystem store contents (fs.store.clear())
   - Closes any open file handles in fs._cache
   - Removes session from all tracking dicts:
     * _sessions
     * _last_accessed
     * _session_metadata

4. New Expiration Tracking Methods:
   - is_session_expired(session_id, timeout_seconds) -> bool
     * Returns False for active session within timeout
     * Returns True for session exceeded timeout
     * Returns True for non-existent session
   - get_expired_sessions(timeout_seconds) -> list[str]
     * Returns all session IDs that have exceeded the timeout
   - get_session_metadata(session_id) -> SessionMetadata | None
     * Returns SessionMetadata if session exists
   - update_session_access(session_id) -> bool
     * Manually updates last_accessed timestamp
     * Returns True if successful, False if session doesn't exist

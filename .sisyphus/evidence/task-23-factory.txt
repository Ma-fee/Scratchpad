Implementation Summary:
-----------------------

1. Filesystem Factory (create_filesystem):
   - Parses MountConfig.source URI to determine backend type
   - Dispatches to appropriate creator based on scheme:
     * file:// -> create_local_filesystem
     * s3:// -> create_s3_filesystem
     * memory:// -> create_memory_filesystem
   - Applies config.options as kwargs to backend
   - Returns configured AbstractFileSystem instance

2. Multi-Mount Factory (create_filesystems_from_config):
   - Takes OverlayConfig with multiple mounts
   - Separates RW mount for upper layer
   - Collects RO mounts for lower layers
   - Sorts lower filesystems by priority (highest first)
   - Returns tuple: (lower_filesystems, upper_filesystem)

3. Added Functions:
   - create_memory_filesystem(): Creates MemoryFileSystem
   - create_filesystem(): Factory for single MountConfig
   - create_filesystems_from_config(): Factory for OverlayConfig

Example Usage:
--------------
    # Single mount
    mount = MountConfig(
        name="test",
        source="file:///tmp/data",
        mount_point="/",
        mode="ro"
    )
    fs = create_filesystem(mount)
    assert isinstance(fs, DirFileSystem)

    # Multiple mounts
    config = OverlayConfig(mounts=[
        MountConfig(name="base", source="file:///base", mount_point="/", mode="ro"),
        MountConfig(name="work", source="memory://", mount_point="/work", mode="rw"),
    ])
    lowers, upper = create_filesystems_from_config(config)
    # lowers: [DirFileSystem(/base)]
    # upper: MemoryFileSystem

4. FEATURES IMPLEMENTED
-----------------------

4.1 ClientCapability Enum
   - IMAGES: Supports image resources (PNG, JPEG, etc.)
   - BINARY: Supports binary resource data
   - SUBSCRIPTIONS: Supports resource subscriptions/notifications
   - THUMBNAILS: Supports thumbnail generation
   - XML_FORMAT: Supports XML wrapper format

4.2 Detection Sources
   - User-Agent header (Claude Desktop, MCP Inspector, etc.)
   - Accept header (MIME type hints)
   - X-MCP-Capabilities header (explicit capability declaration)
   - Case-insensitive header parsing

4.3 Known Client Profiles
   - claude-desktop: Images, Binary, XML, Thumbnails
   - claude-web: Images, XML
   - mcp-inspector: All capabilities
   - mcp-client: Images, Binary, XML

4.4 Format Negotiation
   - negotiate_format() falls back gracefully
   - Custom fallback chains supported
   - Text format is always supported (backward compatible)

4.5 Resource Response Enhancement
   - Includes supported_formats list
   - Includes capability_version
   - Includes format recommendations
   - Optional subscription_supported flag
   - Optional thumbnail_available flag for images

5. USAGE EXAMPLES
-----------------

5.1 Detect capabilities from request:
   ```python
   from mcp_scratchpad.resources.capabilities import detect_client_capabilities
   
   caps = detect_client_capabilities(
       headers={"Accept": "image/png, text/plain"},
       user_agent="Claude-Desktop/1.0"
   )
   # Returns: {ClientCapability.IMAGES, ClientCapability.BINARY, ...}
   ```

5.2 Negotiate format:
   ```python
   from mcp_scratchpad.resources.capabilities import negotiate_format
   
   format = negotiate_format("image", caps)
   # Returns: "image" if supported, else "text"
   ```

5.3 Read resource with capabilities:
   ```python
   from mcp_scratchpad.resources import read_resource, ClientCapability
   
   caps = {ClientCapability.IMAGES, ClientCapability.BINARY}
   result = read_resource(uri, client_caps=caps)
   
   # result.capability_metadata contains:
   # - supported_formats: ["text", "image", "binary"]
   # - capability_version: "1.0"
   # - recommendations: {...}
   ```

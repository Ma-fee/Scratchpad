================================================================================
IMPLEMENTATION DETAILS
================================================================================

create_session():
  - Creates MemoryFileSystem with skip_instance_cache=True
  - Initializes /workspace directory via _init_session_workspace()
  - Stores FS instance in _sessions dict keyed by session_id
  - Associates SessionMetadata with each session

get_session_fs(session_id: str) -> MemoryFileSystem | None:
  - Returns stored MemoryFileSystem for valid session_id
  - Returns None for non-existent session
  - Updates last_accessed timestamp on access

_init_session_workspace(fs: MemoryFileSystem):
  - Creates /workspace directory if it doesn't exist
  - Workaround: MemoryFileSystem.mkdir doesn't support exist_ok

================================================================================
KNOWN LIMITATIONS
================================================================================

1. MemoryFileSystem Storage Is Shared:
   - MemoryFileSystem uses class-level store dict
   - All instances share the same storage
   - Files written in one session are visible to other sessions
   - Phase 2 overlay filesystem will provide true isolation

2. Files Created Before First Session:
   - Since storage is global, files from previous test runs may persist
   - cleanup_session() clears FS.store to mitigate this
   - Tests should clear MemoryFileSystem.store before running if needed

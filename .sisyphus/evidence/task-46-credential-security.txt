## Key Functions Implemented

### mask_sensitive_data(text, rules)
Main entry point - masks all recognized credential patterns in text.

### mask_dict_sensitive_data(data, keys_to_mask)
Recursively masks sensitive keys in dictionaries and nested structures.

### create_secure_log_filter()
Returns a logging.Filter that automatically masks credentials in log records.

### mask_exception_message(exc)
Extracts and masks exception messages.

### likely_contains_credentials(text)
Quick check for performance - scans for sensitive keywords before full masking.

## Masking Strategies

1. **AWS Access Keys**: Partial masking (keep first 4, last 4 chars)
   - Example: `AKIAIOSFODNN7EXAMPLE` → `AKIA****MPLE`

2. **Passwords in URIs**: Replace password part with `***`
   - Example: `postgresql://user:pass@host` → `postgresql://user:***@host`

3. **API Keys/Tokens**: Replace value with `***`
   - Example: `api_key: secret123` → `api_key: ***`

4. **Private Keys**: Replace entire key content
   - Example: PEM block → `***PRIVATE_KEY_CONTENT_MASKED***`

5. **Secrets**: Replace entire value
   - Example: `password=secret` → `password=***`

## Usage Examples

```python
from mcp_scratchpad.security import mask_sensitive_data, create_secure_log_filter

# Mask credentials in string
masked = mask_sensitive_data("URI: postgresql://user:pass@localhost/db")
# Result: "URI: postgresql://user:***@localhost/db"

# Add to logging
import logging
handler = logging.StreamHandler()
handler.addFilter(create_secure_log_filter())
logger = logging.getLogger()
logger.addHandler(handler)

# Mask dictionary
data = {"user": "john", "password": "secret123"}
masked = mask_dict_sensitive_data(data)
# Result: {"user": "john", "password": "***"}
```

## Pattern Design Decisions

1. Regex-based patterns for flexibility and maintainability
2. MaskingRule dataclass for extensibility
3. DEFAULT_MASKING_RULES list for easy rule management
4. Dictionary masking with recursive traversal for complex data structures
5. Chinese inline comments for non-obvious logic
6. Performance-conscious: quick check function for optional optimization

## Implementation Details

### 1. InvalidationEvent Enum
Added enum with values:
- WRITE = "write"
- DELETE = "delete"
- MKDIR = "mkdir"
- RMDIR = "rmdir"
- RENAME = "rename"

### 2. New Methods Added to DirectoryIndexCache

#### `mark_dirty(path: str) -> None`
Marks a path as dirty (invalidated), enabling event-driven invalidation.
Dirty markers take precedence over TTL in hybrid mode.

#### `is_dirty(path: str) -> bool`
Checks if a path or any of its parents are marked dirty.
Uses path traversal up to root to check parent directories.

#### `invalidate_on_event(event_type: str, path: str) -> list[str]`
Invalidates cache entries based on file system events:
- WRITE/DELETE: Invalidates containing directory (parent or grandparent)
- MKDIR/RMDIR: Invalidates parent directory
- RENAME: Invalidates both source and destination parents

Returns list of affected paths that were invalidated.

#### `_get_affected_paths(event: InvalidationEvent, path: str) -> list[str]`
Internal helper that calculates which paths need invalidation based on event type.

#### `clean_dirty(path: str) -> bool`
Removes a path from the dirty set, allowing it to be revalidated.
Returns True if path was dirty and is now clean.

#### `flush() -> None`
Complete cache reset - clears all entries and dirty markers.

### 3. Hybrid Invalidation Logic
The `get()` method now implements hybrid invalidation:
1. First checks if path or any parent is dirty (event-driven invalidation)
2. Then checks TTL expiration
3. Returns None if either check fails

Dirty markers take precedence over TTL - even entries with valid TTL are
considered invalid if marked dirty.

### 4. Invalidation Logic by Event Type

```
WRITE/DELETE on /parent/child/file.txt -> invalidate /parent
WRITE/DELETE on /parent/child -> invalidate /parent
MKDIR/RMDIR on /parent/child -> invalidate /parent
RENAME /src/file.txt -> /dst/file.txt -> invalidate both /src and /dst
```

## QA Scenario Verification

### Scenario 1: Event-driven invalidation
```python
cache.set("/parent", ["child/"], ttl=60)
cache.invalidate_on_event("write", "/parent/child/file.txt")
result = cache.get("/parent")  # Returns None (invalidated)
```
✅ Verified: Parent directory cache invalidated

### Scenario 2: Hybrid mode prefers dirty over TTL
```python
cache.set("/test", ["file1"], ttl=60)
cache.mark_dirty("/test")
result = cache.get("/test")  # Returns None despite valid TTL
```
✅ Verified: Dirty marker takes precedence over TTL

### Scenario 3: Parent directory invalidation on child change
```python
cache.set("/parent", ["child"], ttl=60)
cache.invalidate_on_event("mkdir", "/parent/newdir")
result = cache.get("/parent")  # Returns None
```
✅ Verified: Parent directory invalidated on child mkdir

### Scenario 4: Flush clears all entries
```python
cache.set("/path1", ["a"], ttl=60)
cache.set("/path2", ["b"], ttl=60)
cache.mark_dirty("/path1")
cache.flush()
# cache.size == 0, cache.is_dirty("/path1") == False
```
✅ Verified: All entries and dirty markers cleared

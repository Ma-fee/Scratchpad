Implementation Summary
----------------------
Implemented mkdir() and makedirs() methods in OverlayFileSystem class:

1. mkdir(path, create_parents=False, **kwargs)
   - Creates single directory in upper layer only
   - If create_parents=True: delegates to upper.makedirs()
   - If create_parents=False: validates parent exists, then calls upper.mkdir()
   - Raises FileExistsError if directory already exists in upper layer

2. makedirs(path, exist_ok=False, **kwargs)
   - Creates directory and all parent directories in upper layer only
   - If exist_ok=True: returns without error if directory exists
   - If exist_ok=False: raises FileExistsError if directory exists
   - Delegates to upper.makedirs() with exist_ok=False

Key Design Decisions:
  - All writes go to upper layer only (lower layers are read-only)
  - Path normalization is applied to ensure consistent behavior
  - Error handling follows fsspec conventions (FileExistsError, FileNotFoundError)
